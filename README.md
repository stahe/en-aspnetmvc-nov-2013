# Introduction to ASP.NET MVC through examples (November 2013)

This repository contains the **HTML** version of the document *Introduction to ASP.NET MVC through examples*, originally published in **November 2013**. 

The aim is to introduce, through examples, the key concepts of **ASP.NET MVC**, a .NET web framework based on the **MVC (Model – View – Controller)**. 

## Read the document online

* Document website: [https://stahe.github.io/en-aspnetmvc-nov-2013/](https://stahe.github.io/en-aspnetmvc-nov-2013/)
## Prerequisites

Understanding the examples requires few prerequisites; a **basic knowledge of C#** is sufficient.
